# 汉字拼字 · 合字工坊（REQ-HZ001）

## 背景

平台已有拼音、点字成诗等语文向游戏，但缺少「汉字结构与部件意识」的启蒙玩法。小学识字教学中，「日 + 月 = 明」「女 + 子 = 好」这类合体字拆分是核心方法论；把它做成点选两部件合成目标字的游戏，既能练识字，又能建立部件组合直觉。

## 目标与范围

**本次覆盖**：
1. 玩法「合字工坊」：每关给出部件池（大号部件卡）与目标清单；点两个部件，若能组成目标清单中的字则合成成功（两卡飞入合成台动画，目标字卡亮起并展示拼音与例词），否则抖动提示并计一次失误。
2. 组合判定顺序无关（日+月 与 月+日 均为 明）。
3. 题库 `hanndata.js`：不少于 48 个两部件直观组合的常用合体字，每字含 `char / parts[2] / pinyin / word`，同一部件组合在全库内唯一。
4. 12 关递进：1-4 关 3 字/关（部件池 6）、5-8 关 4 字/关（池 8）、9-12 关 5 字/关（池 10）；种子随机生成，同种子可复现。
5. 星级：0 失误 ★★★、失误 ≤3 ★★、其余 ★；失误指点错组合的次数，不阻断游戏。
6. 存档（key 前缀 `hanzi-parts-`）：`unlocked-level`（只增不减）、`stars-<level>`（保留最大值）；提供关卡选择弹窗与重开按钮。

**本次不覆盖**：多部件字（三拼及以上）、有声发音、错题本、跨设备同步。

## 用户角色

- 学龄前与小学低年级儿童：通过部件拼合认识合体字，例词辅助理解字义。
- 家长/教师：用作识字启蒙练习，星级反映本关熟练度。

## 页面清单

- 游戏页 `src/hanzi-parts/index.html`：页头（关卡徽章）、状态栏（目标进度/失误/当前星级）、目标清单、合成台、部件池、操作区（重开本关/关卡选择）、过关弹窗、关卡选择弹窗。
- 题库 `src/hanzi-parts/hanndata.js`：`window.HanziPartsData` 数据文件。
- 逻辑 `src/hanzi-parts/script.js`：暴露 `window.HanziApi` 纯函数与存档函数。
- 样式 `src/hanzi-parts/style.css`：自包含 `--hz-*` 变量，儿童向明亮配色。
- 冒烟测试 `src/hanzi-parts/smoke.test.js`：node 原生 assert + vm 沙箱。

## 核心流程

1. 进入游戏 → 载入最新解锁关卡 → 渲染目标清单（问号占位）、合成台（空槽）与部件池。
2. 点第一个部件卡 → 高亮并落入合成台第一个槽位；再点第二个部件卡 → 两卡飞入合成台。
3. 组合命中目标清单 → 两卡消耗置灰，目标字卡亮起展示拼音与例词，合成台弹出结果字。
4. 组合未命中目标清单 → 两卡与合成台抖动报错，失误 +1，当前星级预览随之下降。
5. 集齐全部目标字 → 结算：按失误定星、写存档（星级取最大、解锁下一关）、弹过关面板（含本关所学字与例词）。
6. 关卡选择弹窗：已解锁关卡可点（显示历史星级），未解锁置灰；重开按钮重置本关（同种子同布局）。

## 关键业务对象

- **字条目**：`{ char, parts: [a, b], pinyin, word }`；`parts` 排序后拼接构成组合键（如 `月+日` → `日+月`），全库唯一。
- **关卡配置**：`levelConfig(level)` → `{ targetCount, poolSize }`；三档 3/6、4/8、5/10。
- **关卡实例**：`generateLevel(level, seed)` → `{ targets: 字条目[], pool: 部件[] }`；目标字两两部件对互不相同；部件池 = 全部所需部件（去重）+ 干扰部件，互异。
- **星级**：`starRating(mistakes)`：0 → 3；1-3 → 2；≥4 → 1。
- **存档**：`hanzi-parts-unlocked-level`、`hanzi-parts-stars-<level>`；读写均带兜底（存储不可用时退化为内存）。

## 边界场景与异常

- 组合命中题库但不在本关目标清单（如池中干扰部件与所需部件凑成本关以外的字）：按未命中处理计一次失误，但给出具体提示（「拼得出来，但不是本关目标」），不误导航童。
- 同部件字（林=木+木、朋=月+月等）：保留在题库供查询；因部件池互异（每个部件仅一张卡）不作为关卡目标字，生成器自动跳过。
- 动画进行中（locked）：忽略新的点击，防连点导致的判定错乱。
- localStorage 不可用（隐私模式/测试环境）：读写退化为内存兜底，游戏流程不中断。
- 题库文件加载失败：`DATA` 降级为空数组，页面骨架仍可渲染，不抛异常。

## 非功能要求

- 纯静态、无构建、无框架、无新增第三方依赖/CDN；直接打开 HTML 即可玩。
- 移动端适配：`viewport-fit=cover, user-scalable=no`；触控目标 ≥ 44px；顶部内容避让左上角悬浮返回按钮（页头区 padding-top ≥ 56px）。
- 全部文件 UTF-8，注释一律中文；交互零 alert/confirm；JS 使用 ES6+，禁 var/eval/==。
- 冒烟测试 `node src/hanzi-parts/smoke.test.js` 直接跑通，覆盖文件约定、题库质量、12 关生成、星级与存档。

## 验收标准

1. 题库 ≥ 48 字（实际 70 字），每字恰 2 个部件且 pinyin/word 非空；全部组合键唯一。
2. 12 关生成满足：目标字数 3/4/5 递进、部件池 6/8/10、池含全部所需部件且互异、目标部件对两两不同、同种子可复现。
3. 点两个部件：命中目标清单的字成功合成并亮起目标卡（含拼音与例词）；未命中抖动并失误 +1；判定顺序无关。
4. 星级边界正确（0/≤3/其余）；过关后解锁只增不减、星级保留历史最大。
5. 关卡选择弹窗可切换已解锁关卡，未锁定之外的关卡置灰；重开本关布局不变（同种子）。
6. `node src/hanzi-parts/smoke.test.js` 输出 `hanzi parts smoke test passed`。
7. 页面含 `viewport-fit=cover`、`user-scalable=no`，`</body>` 前依次引入 `hanndata.js`、`script.js`、`../js/game-back.js`。
