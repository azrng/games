# 打砖块 · 核心玩法（REQ-BK001）

## 背景

平台"手速休闲"空缺（见 REQ-SN001 背景）；打砖块与贪吃蛇互补——一个练反应走位，一个练预判控板，同为零学习成本经典。

## 目标与范围

**本次覆盖**：
1. 经典打砖块：控制挡板反弹小球击碎砖阵，球落底扣命，砖清空过关。
2. 关卡递进：6 关，砖阵布局由关卡种子确定性生成（行数、列数、砖块密度随关卡递增），同关布局可复现。
3. 手感核心：反弹角度随击中挡板的位置变化（中间直上、边缘斜抛），球速随关卡与时间缓增（设上限）。
4. 命制：3 条命，球落底扣 1 命并重置球于挡板上方待发射；命尽游戏结束。
5. 双端操控：PC 鼠标移动 / 方向键；移动端拖动挡板（跟手，非滑动判定）。
6. 计分与纪录：每砖 10×关卡分；显示总分、本关进度（剩余砖数）、最高总分；关卡推进解锁记录，通关后可从任一已解锁关开始。
7. 结算：过关（下一关）/ 通关（庆祝 + 总分）/ 失败（总分 + 最高分 + 破纪录标识）三种弹窗。
8. 接入平台首页游戏目录（age: all，device: all）。

**本次不覆盖**：道具掉落（加长挡板/多球等）、砖块血量与特殊砖、皮肤主题、关卡编辑器。

## 用户角色

- **青少年（10-18 岁）**：主要玩家，鼠标/触屏操作熟练。

## 页面清单

- **对局页**（单页游戏）：页头（游戏名 + 关卡胶囊）、棋盘 canvas、计分板（总分/本关剩余/命）、操作说明、操作栏（开始/重开/选关）、弹窗（过关/通关/失败/选关列表）。
- 平台首页卡片（注册项）。

## 核心业务流程

1. 进入页面：从第 1 关（或最近解锁关）待机，提示"点开始"。
2. 开始后球贴在挡板上方，点击/按空格发射；移动挡板接球。
3. 球撞砖：砖消失、加分、球反弹（按碰撞面判定反弹轴）；砖清空 → 过关弹窗 → 下一关（解锁记录持久化）。
4. 球落底：扣 1 命，球重置待发射；命尽 → 失败弹窗（总分、最高分、破纪录标识）。
5. 第 6 关通关 → 通关庆祝弹窗；可从操作栏打开选关弹窗，在已解锁关卡中跳关。
6. 刷新后解锁进度与最高分保留。

## 关键业务对象及字段含义

- **砖阵布局（layout）**：二维布尔阵，由 `generateLayout(level, seedBase)` 确定性生成——同关种子同布局；行数 = min(4+关卡, 7)、列数 10、密度随关卡提高。
- **反弹角（reflect）**：球撞挡板时按命中点相对挡板中心偏移（-1~1）映射出射角（约 30°~150°），保证手感可控。
- **命（lives）**：3 起，扣至 0 结束。
- **解锁进度（unlocked-level）**：历史到达的最大关卡号。
- **最高分（best）**：历史最高总分。

## 权限与可见范围

无账号体系，仅本机存档。

## 边界场景与异常

- **球速过快穿砖/穿板**：步进按最大位移分片检测，杜绝高速穿透。
- **球水平死循环**：出射角限制在非水平区间（垂直分量下限），反弹角映射天然规避。
- **对局中刷新/关页**：本局不计，解锁进度与最高分已实时持久化。
- **本地存储不可用**：可完整游玩，仅不记进度与最高分。
- **拖动越出棋盘**：挡板钳制在边界内。

## 非功能要求

- canvas 渲染流畅、跟手无迟滞；移动端挡板拖动映射考虑 canvas 缩放比例。
- 技术形态与仓库现状一致：无框架、无构建、静态单页、UTF-8、中文注释，不新增第三方依赖。

## 验收标准

1. 平台首页出现「打砖块」卡片，可正常进入游玩。
2. 鼠标/方向键/触屏拖动均可控板；反弹角随击中位置可感知变化。
3. 同一关卡多次进入布局一致；不同关卡布局与难度递增。
4. 砖清空过关并解锁下一关；命尽失败；第 6 关通关有庆祝结算。
5. 刷新后解锁进度与最高分保留；选关弹窗仅开放已解锁关。
6. smoke test（node 直跑）通过，覆盖布局生成确定性、反弹角映射、砖碰撞轴判定、命与状态流转、存档读写。
