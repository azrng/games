# 游戏平台首页 · 设备筛选 Tab（REQ-GH002）

## 背景

首页已有年龄筛选（REQ-GH001），但游戏的设备适配差异同样明显：迷宫冒险、俄罗斯方块仅电脑端可玩，另有 6 款游戏在桌面宽度下明确提示「请在手机上体验」。用户在电脑上点到玩不了的游戏、或在手机上点到键盘游戏时缺少预期管理手段。需要一个与年龄筛选并列的轻量设备筛选入口。

## 目标与范围

**本次覆盖**：
1. 首页年龄筛选下方新增设备筛选 Tab：「全部 / 电脑端 / 移动端」，默认「全部」。
2. 筛选语义与年龄维度一致的包含关系：
   - 「全部」= 所有游戏（16 款）。
   - 「电脑端」= 仅电脑端 + 双端（隐藏仅移动端游戏）。
   - 「移动端」= 仅移动端 + 双端（隐藏仅电脑端游戏）。
3. 每款游戏在数据层 `meta` 内标注设备适配分类，分类缺失时按「全部设备」兜底展示（不隐藏）。
4. Tab 上展示当前分类的游戏数量；数量独立于另一筛选维度（年龄 Tab、设备 Tab 各自对全目录计数），由数据实时推导，不硬编码。
5. 年龄与设备两维度同时生效，列表展示两个筛选的交集。

**本次不覆盖**：游戏卡片上的设备徽章、`mobilePath` 机制调整、筛选状态持久化、单游戏页任何改动。

## 用户角色

- 电脑端用户：不想点到需要触屏的手机专属游戏。
- 移动端用户：不想点到需要键盘或明确不支持移动端的桌面专属游戏。
- 家长/成人用户：与年龄筛选叠加收窄浏览范围。

## 页面 / 模块清单

- 平台首页 `index.html`（设备 Tab 区域新增）
- 数据层 `src/data/games.js`（目录条目增加设备适配分类）
- 渲染层 `src/js/app.js`（设备维度筛选、交集与重渲染逻辑）
- 样式 `src/css/custom.css`（两行 Tab 组间距与移动端适配）

## 核心业务流程

1. 进入首页，默认「全部 / 全部」双选中，展示全部游戏。
2. 点击「电脑端」：列表收窄为仅电脑端 + 双端游戏。
3. 点击「移动端」：列表收窄为仅移动端 + 双端游戏。
4. 与年龄 Tab 叠加：列表展示两维度交集（如「儿童 + 移动端」= 13 款）。
5. 刷新页面回到默认「全部 / 全部」。

## 关键业务对象：设备适配分类

`meta` 内新增「设备适配分类」字段（`meta.device`），取值三选一：

| 取值 | 含义 | 首页哪些 Tab 可见 |
| --- | --- | --- |
| `desktop` | 仅电脑端（依赖键盘或明确提示不支持移动端） | 全部、电脑端 |
| `mobile` | 仅移动端（桌面宽度显示「请在手机上体验」） | 全部、移动端 |
| `all` | 双端（无明确设备倾向或已适配两端输入） | 全部、电脑端、移动端 |

初始归类（依据各游戏页面实际适配证据，2026-10-08 确认）：

| 游戏 | 归类 | 依据 |
| --- | --- | --- |
| 迷宫冒险、俄罗斯方块 | desktop | 页面自带「桌面端专用」提示层 / 仅键盘方向键控制，无触控代码 |
| 色觉挑战、数字华容道、一笔画、转管道、点灯、扫雷 | mobile | 桌面宽度（≥769px）显示「请在手机上体验」，游戏壳隐藏 |
| 找猫咪 | mobile | 依赖双指缩放手势，桌面无对应交互 |
| 2048、五子棋、动物翻翻棋、单词大炮、数学小勇士、点字成诗、拼音打字乐园 | all | 均有双端输入证据（键盘+滑动、独立 mobile.html、点击操作、软键盘、内置虚拟键盘） |

## 权限与可见范围

无权限模型。筛选仅影响首页展示，不影响任何游戏的可用性与链接。

## 边界场景与异常

- 目录数据缺失或为空：维持现状（不渲染列表），两行 Tab 区域均不渲染。
- 交集筛选下没有游戏：列表区显示空态提示文案，不显示空白。
- 条目缺少设备字段或取值非法：按「全部设备（all）」兜底，保证游戏不被错误隐藏。
- 移动端：两行 Tab 均可换行，不横向溢出。

## 非功能要求

- 保持无构建、无后端、无新增第三方依赖；静态打开首页即可用。
- 筛选为纯前端同步过滤，切换无感知延迟；不引入 loading 状态。

## 验收标准

1. 默认进入首页两行 Tab 均选中「全部」，展示 16 款游戏。
2. 年龄 Tab 计数为 16/15/11，设备 Tab 计数为 16/10/14，且数量实时推导。
3. 点「电脑端」后列表为 10 款，不含色觉挑战、数字华容道、一笔画、转管道、点灯、扫雷、找猫咪。
4. 点「移动端」后列表为 14 款，不含迷宫冒险、俄罗斯方块。
5. 「儿童 + 移动端」交集为 13 款；「成人 + 移动端」交集为 9 款，不含俄罗斯方块与迷宫冒险。
6. 将某款游戏的设备字段删除或改为非法值后，该游戏在设备 Tab 下均可见（兜底生效）。
7. 刷新页面回到「全部 / 全部」；两行 Tab 均支持键盘聚焦与回车切换。
