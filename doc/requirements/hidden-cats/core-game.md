# 找猫咪 · 核心玩法（REQ-HC001）

> 迁移自 `doc/requirement.md` 第三章（2026-10-08 按模块拆分）。功能已交付（`src/hidden-cats/`），并在此基础上迭代出场景主题、关卡选择等扩展；本文档作为已交付需求的记录基准；原「待确认项」保留为历史记录。

## 项目背景

"找猫咪"是一款视觉搜索类休闲游戏，系统程序化生成一幅密集的素描风格画面，其中隐藏了多只猫咪，玩家需要通过缩放和平移画面，逐一找到所有隐藏的猫咪。游戏结合了视觉辨识力与耐心，画面每次随机生成，无限可玩。

## 目标与范围

- 目标：为游戏平台新增一款移动端"找猫咪"游戏，画面由程序动态生成，每关随机隐藏 N 只猫咪，玩家点击找到所有猫咪后通关。
- 范围：仅实现移动端单页面游戏，不提供 PC 端适配；不涉及用户登录或在线排行榜。

## 用户角色

- 玩家：所有通过移动端浏览器访问游戏平台的用户，无角色区分。

## 画面生成机制

### 场景构成

- 画面由 Canvas 绘制，采用素描/简笔风格。
- 场景元素分层叠加：
  - **背景层**：浅色底色 + 随机几何纹理（格子、圆点、斜线等）增加视觉复杂度。
  - **干扰层**：大量随机绘制的小物件（树、房子、花、瓶子、书本、星星、云朵等简笔图形），这些物件与猫咪共享相似的线条风格和大小范围，构成视觉干扰。
  - **猫咪层**：在干扰物之间随机放置猫咪图案，猫咪朝向、大小、姿态随机微调（旋转 ±30°、缩放 0.8x–1.2x），使猫咪融入画面但仔细看可辨识。

### 猫咪绘制

- 猫咪由代码绘制简笔轮廓：圆形头部 + 三角耳朵 + 椭圆身体 + 弯曲尾巴 + 眼睛和胡须。
- 不同猫咪可随机选择几种变体：坐姿、趴姿、蜷缩、伸懒腰等。
- 猫咪颜色与线条粗细与周围干扰物接近，不突出显示。

### 关卡配置

| 参数 | 说明 | 随关卡递增规则 |
|------|------|----------------|
| 猫咪数量 | 本关需要找到的猫数 | 起始 3 只，每 3 关 +1，上限 10 只 |
| 画布尺寸 | 可探索的画面区域 | 起始 1200×1200px，随关卡递增至 3000×3000px |
| 干扰物数量 | 随机物件的数量 | 猫数的 5–8 倍 |
| 干扰物相似度 | 干扰物与猫的形态接近程度 | 高关卡出现更多"像猫但不是猫"的干扰物 |

## 核心业务流程

### 游戏主循环

1. 系统按当前关卡配置程序化生成画面，随机放置猫咪与干扰物。
2. 画面初始以缩放状态展示，玩家可双指缩放和单指平移浏览。
3. 画面顶部显示进度条：`已找到 2/5 只猫咪`。
4. 玩家点击画面中的猫咪位置：
   - **命中猫咪**：猫咪被圈出标记（圆圈动画 + 计数更新 + 短暂音效反馈），该猫咪不可再次点击。
   - **未命中**：点击位置显示一个 × 标记，短暂停留后消失，作为无效反馈。
5. 所有猫咪被找到后，本关通关，展示结算面板（本关用时、累计通关数）。
6. 玩家选择"下一关"继续挑战，难度自动递增。

### 命中判定

- 玩家点击位置与猫咪中心点的欧几里得距离 ≤ 猫咪绘制半径的 1.2 倍时判定为命中。
- 考虑到触控精度，判定范围适当放宽，避免玩家明明点对了却判错。

## 关键业务对象及字段

| 数据项 | 存储方式 | 说明 |
|--------|----------|------|
| 当前关卡 | 页面内存 | 当前处于第几关 |
| 猫咪位置列表 | 页面内存 | 本关所有猫咪的中心坐标和命中半径 |
| 已找到数量 | 页面内存 | 当前已找到的猫咪数 |
| 已找到标记 | 页面内存 | 记录哪些猫咪已被找到，避免重复点击 |
| 本关用时 | 页面内存 | 从画面展示开始计时 |
| 累计通关数 | localStorage | 历史最高通关关数，前缀 `hidden-cats-` |
| 画布状态 | 页面内存 | 当前缩放比例和平移偏移，用于重绘 |

无权限模型，不涉及用户登录与账号体系；成绩仅保存在本机浏览器。

## 交互说明

- 进入游戏自动生成第 1 关画面并展示。
- 双指捏合缩放画面（0.5x–3x），单指滑动平移画面。
- 点击画面即判定是否命中猫咪，命中时播放圈出动画并更新计数。
- 点击"提示"：随机将一只未找到的猫咪区域高亮闪烁 2 秒后恢复，每关限用 2 次。
- 点击"重置缩放"将画面恢复到初始缩放和居中状态。
- 通关后弹出结算面板，点击"下一关"生成新关卡。
- 横竖屏切换时画布自动重新计算视口。

## 边界场景与异常

| 场景 | 处理方式 |
|------|----------|
| 缩放到极限 | 设置最小 0.5x、最大 3x 缩放阈值 |
| 误触与点击冲突 | 区分滑动（平移）和点击（判定）：滑动距离 > 10px 视为平移，否则为点击判定 |
| 提示次数用尽 | 提示按钮变为禁用状态 |
| 后台切换回来 | 游戏状态保持，不重置 |
| 高关卡画面复杂度高 | Canvas 分块绘制，只渲染当前视口可见区域，避免卡顿 |

## 非功能要求

- 页面首屏加载 < 1.5s（程序生成画面，无外部图片资源）。
- 画面使用 Canvas 2D 绘制，视口裁剪优化保证流畅。
- 双指缩放和平移操作流畅，无明显延迟。
- 支持 iOS Safari 和 Android Chrome 最近两个主版本。
- 视口设置 `width=device-width, initial-scale=1.0, user-scalable=no`。

## 验收标准

> 以下标准为迁移时依据原文流程、边界与既有实现归纳补充。

1. 进入游戏自动生成第 1 关画面（Canvas 程序化绘制，无外部图片资源）。
2. 双指缩放受 0.5x–3x 阈值限制，单指平移可用；滑动距离 > 10px 不触发点击判定。
3. 点击命中猫咪（判定半径为绘制半径的 1.2 倍）时圈出标记、进度 +1，且该猫不可重复点击；未命中显示短暂 × 反馈。
4. 全部猫咪找到后弹出通关结算，"下一关"按递增规则生成更高难度关卡。
5. 提示每关限 2 次，用尽后按钮禁用；累计通关数按 `hidden-cats-` 前缀持久化。
