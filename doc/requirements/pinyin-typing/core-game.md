# 拼音打字乐园 · 核心玩法（REQ-PT001）

## 背景

平台现有游戏偏成人或通用益智（单词大炮面向成人英语学习），缺少面向儿童的键盘启蒙游戏。家长希望在孩子学拼音的阶段（学前大班~小学低年级），用打字的方式同时巩固拼音拼读与识字，并熟悉键盘。

经需求澄清与 grill-me 拷问确认的关键决策：
- 目标年龄 **5-8 岁**（学前大班~小学二年级），产品文案不使用「幼儿」（3-4 岁不具备实体键盘打字能力，8 岁以上学校才系统教指法）。
- 内容以**汉字**为主：看汉字打其全拼（不输入声调）。
- 输入**仅 PC 物理键盘**，不做触屏虚拟键盘。
- **全档零失败**，屏幕键位图高亮引导。
- 激励采用**星星 + 贴纸册**；对局采用**每局 8 字短局制**；游戏名「拼音打字乐园」（slug `pinyin-typing`）。

## 目标与范围

**本次覆盖**：
1. 三档难度：启蒙档（5-6 岁）、基础档（6-7 岁，一年级）、挑战档（7-8 岁），进游戏先选档。
2. 看汉字打全拼核心玩法：汉字卡片 + 插图 + 自动朗读，拼音槽位逐字母点亮。
3. 键位引导：屏幕常驻 26 字母键位图，高亮下一个待按键；大小写输入均接受。
4. 零失败设计：按错仅卡片抖动 + 按键闪红，无扣分、无计时、无失败结算；挑战档额外显示连击统计（纯展示、不惩罚）。
5. 短局制：每局 8 个字，完成后进入结算页（本局星级、新点亮贴纸、鼓励语）。
6. 进度持久化：每字历史最佳星级（1-3 星）、各档最高连击、声音开关，存本机浏览器；贴纸由星级派生（打过即点亮）。
7. 内置字库对齐部编版语文课本生字（经用户确认的全量方案，共 1081 条）：启蒙档 211 字（一年级上册）、基础档 287 字（一年级下册新增）、挑战档 583 条（二年级新增 563 字 + 常用双字词 20 条）。字库由生成管道（`build-wordbank.js`）从课本数据生成，不手工逐条维护；插图与例词是可选增强——精选字保留配图与例词，其余字降级为大字+拼音卡、朗读只读汉字。
8. 接入平台首页游戏目录（`src/data/games.js`）。

**本次不覆盖（后置项）**：听写变体（隐藏汉字）、触屏虚拟键盘、声调输入、家长报告页、多存档、自定义字库导入、句子级练习。

## 用户角色

- **儿童（5-8 岁）**：直接玩家，识字量少，依赖插图、语音朗读和键位高亮；不要求会拼读全部音节。
- **家长**：负责选档、判断适配度、开关声音；不需要注册或任何账号操作。

## 页面清单

- **选档页**（游戏菜单）：三档卡片（档位名、年龄、贴纸进度、星星总数）、声音开关、一行玩法说明。
- **对局页**：汉字卡片（汉字/插图/拼音与声调展示/示例词）、拼音槽位、26 字母键位图、局进度、（挑战档）连击显示、重听。
- **结算页**：本局每字星级、新点亮贴纸、最高连击（挑战档）、再来一局 / 回选档。
- 平台首页卡片（注册项，非本模块页面）。

## 核心业务流程

1. 从平台首页进入游戏 → 选档页 → 点击档位卡片开始该档对局。
2. 每局从该档字库取 8 字：**优先取尚未点亮贴纸的字**（打乱顺序），不足 8 个时用已掌握字随机补齐——保证练习始终有新目标。
3. 每个字：卡片出现时自动朗读一次（点卡片可重听）→ 孩子按物理键盘依次输入拼音字母 → 按对点亮槽位且键位图高亮移动到下一键；按错只抖动提示。
4. 整字拼完 → 庆祝动画 + 语音鼓励 → 记录该字星级 → 自动进入下一个字（无需点击）。
5. 8 字完成 → 结算页展示本局成果与累计进度 → 「再来一局」或「回选档」。
6. 每字完成即写入本地存档，刷新或关闭浏览器后进度保留。

## 关键业务对象及字段含义

- **字库条目**：汉字、拼音字母（小写、不含声调）、声调（仅展示）、插图、示例词。结构见 CON-PT001。
- **档位**：启蒙 / 基础 / 挑战三档，各自独立字库与进度，互不影响。
- **星级**：单字单局评价 1-3 星（按本字按错次数：0 次 3 星、1-2 次 2 星、更多 1 星），存档只记历史最佳。
- **贴纸**：某字打过（星级 ≥1）即在该档贴纸册点亮，按档分组展示进度（如 12/40）。
- **连击**：连续按对字母的次数（挑战档展示），断连归零，存档位历史最高。

## 权限与可见范围

无账号体系，进度存本机浏览器。声音开关对儿童可见，无家长专属功能区。

## 边界场景与异常

- **中文输入法开启**：游戏只监听物理键盘按键（keydown）的字母键；选档页提示家长切换到英文输入法（仅提示文案，不做检测）。
- **无中文语音环境**：自动朗读静默降级（不报错、无占位弹窗），拼音照常显示，玩法完整可用。
- **本地存储不可用**（隐私模式等）：对局可完整进行，仅进度不保留；首次进入时提示一次「进度将不会保存」。
- **对局中退出**：Esc 或返回随时回选档，无任何惩罚（零失败原则）；平台返回按钮回首页。
- **乱按/连按**：只响应字母键，其余键忽略；快速连按按输入顺序逐个匹配。
- **存档损坏**：读取失败时重置为全新进度，不崩溃。

## 非功能要求

- 视觉：大字号（汉字为绝对视觉主体）、高对比、卡通亲和配色；动画用 CSS 实现，轻量流畅。
- 响应：按键到视觉反馈即时（感知无延迟）。
- 技术形态与仓库现状一致：无框架、无构建、静态单页、UTF-8、中文注释，不新增第三方依赖。

## 验收标准

1. 平台首页出现「拼音打字乐园」卡片，点击进入选档页。
2. 三档独立可玩，各档贴纸进度与星星数独立显示、独立累计。
3. 对局中：自动朗读播报、槽位按序点亮、键位图高亮随进度移动、按错无任何惩罚反馈。
4. 每字完成有庆祝与计星，8 字后进入结算页，结算数据与本局一致。
5. 刷新页面后贴纸、星级、最高连击、声音开关均保留。
6. 挑战档对局显示当前连击与本局最高连击；启蒙/基础档不显示。
7. 无语音环境与隐私模式下游戏可完整游玩（对应降级行为生效）。
8. smoke test（node 直跑）通过，覆盖取字规则、判键、星级计算、存档读写。
