# 贪吃蛇 · 核心玩法（REQ-SN001）

## 背景

平台现有游戏偏解谜与教育，缺少"手速休闲"类调剂玩法；10-18 岁用户需要经典、上手即玩、单手可玩的动作休闲游戏。贪吃蛇是零学习成本的最优选择。

## 目标与范围

**本次覆盖**：
1. 经典贪吃蛇：网格棋盘（20×20），控制蛇移动吃食，蛇身变长，撞墙或撞自己结束。
2. 节奏递进：初始中速，每吃 4 个食物提速一档（设上限），保持紧张感但不失控。
3. 双端操控：PC 方向键 / WASD；移动端在棋盘上滑动手势转向。方向输入带缓冲队列（最多缓存 2 次转向），且禁止 180° 直接掉头。
4. 计分与纪录：吃 1 个食物 +10，实时显示本局得分、蛇身长度与历史最高分。
5. 暂停/继续：按钮与空格键均可，暂停时棋盘遮罩提示。
6. 结束结算：得分、是否破纪录、最高分；一键再来一局。
7. 接入平台首页游戏目录与年龄/设备筛选（age: all，device: all）。

**本次不覆盖**：皮肤/主题商店、障碍物模式、双人模式、关卡制、道具系统。

## 用户角色

- **青少年（10-18 岁）**：主要玩家，熟悉触屏与键盘操作，追求分数与手感。

## 页面清单

- **对局页**（单页游戏）：页头（游戏名 + 最高分胶囊）、棋盘、计分板（得分/长度/最高分）、操作说明一行字、操作栏（开始/暂停/重开）、结束弹窗。
- 平台首页卡片（注册项，非本模块页面）。

## 核心业务流程

1. 进入页面即待机：棋盘中央显示"点开始或按空格"提示。
2. 开始后蛇以固定间隔移动；玩家通过键盘或滑动改变方向，转向进入缓冲队列依次生效。
3. 蛇头吃到食物：蛇身 +1、得分 +10、生成新食物（不出现在蛇身上）、累计提速。
4. 撞墙或蛇头撞到蛇身 → 对局结束，弹出结算（本局得分、最高分、破纪录标识）。
5. 刷新或退出后最高分保留；对局中退出无惩罚。

## 关键业务对象及字段含义

- **蛇（snake）**：有序格坐标数组，首元素为蛇头；移动即头部入列、尾部出列（吃食时尾部不出列）。
- **方向（direction）**：上下左右四值；缓冲队列确保连续快速输入按序生效；队列中禁止与上一生效方向相反。
- **食物（food）**：随机空格坐标，不与蛇身重叠。
- **速度（speed）**：移动间隔毫秒数，吃食驱动递减，有下限。
- **最高分（best）**：本机历史最高得分。

## 权限与可见范围

无账号体系，仅本机存档。

## 边界场景与异常

- **快速连按两个方向**：进入缓冲队列按序生效，不丢输入、不掉头。
- **对局中刷新/关页**：本局不计、无残留；最高分已实时持久化。
- **本地存储不可用**（隐私模式）：可完整游玩，仅不记最高分。
- **滑动与其他手势冲突**：仅在棋盘区域响应滑动，页面不因此滚动。

## 非功能要求

- 棋盘渲染流畅（canvas 绘制，感知无卡顿）；移动端触控区域足够大。
- 技术形态与仓库现状一致：无框架、无构建、静态单页、UTF-8、中文注释，不新增第三方依赖。

## 验收标准

1. 平台首页出现「贪吃蛇」卡片，可正常进入游玩。
2. 键盘与滑动均可转向；快速连按不丢转向、不能 180° 掉头。
3. 吃食加分、变长、提速；食物不生成在蛇身上。
4. 撞墙/撞身立即结束并弹结算；最高分刷新后保留。
5. 暂停后棋盘静止，继续后恢复。
6. smoke test（node 直跑）通过，覆盖移动步进、吃食、碰撞、方向队列禁反向、最高分读写。

## 待确认项

- 无（玩法经典、范围收敛，直接按本需求执行）。
