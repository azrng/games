# 单词大炮 · 听写模式（REQ-TC003）

## 背景

词义回忆（看中文拼英文）训练"形→义"检索，但缺少"音→形"链路。成人学习者普遍存在"认识词却听不出 / 拼不对"的问题。浏览器原生语音合成（Web Speech API）已因结算发音功能引入，具备零依赖做听写的条件。

## 目标与范围

**本次覆盖**：
1. 听写局：成人词包分组标题上新增"🎧 听写"入口；点击后以该词包随机 10 个词生成一局听写——气泡**不显示单词与释义**，只显示喇叭图标与字母进度槽，单词由语音合成朗读。
2. 播放控制：词进入视野时自动朗读一次；点击气泡可重听；朗读期间半速下坠（与词义关预展示节奏一致）。
3. 学习反馈：词被击碎时飘出"单词 + 释义"揭示；漏接 / 打错的词照常进入错词本（连对 / 毕业规则共用 REQ-TC002）。
4. 能力降级：浏览器不支持语音合成时，听写入口不显示，其余功能不受影响。

**本次不覆盖**：按难度排序的听写词表、语速分级设置、美音/英音选择、听写历史统计。

## 用户角色

碎片时间成人学习者（与 REQ-TC001 一致）；儿童模式不提供听写入口。

## 页面清单

- 选关菜单页：每个成人词包分组标题右侧新增"🎧 听写"小按钮（不支持语音的环境不渲染）。
- 游戏页：复用现有画布；听写气泡为词义气泡的变体（喇叭 + 进度槽，无释义文字）。
- 结算页：复用生词区块；听写局结算显示"听写词数"与提示文案。

## 核心业务流程

1. 玩家点成人词包分组上的"🎧 听写" → 生成 10 词听写局。
2. 词进入视野自动朗读；玩家点击气泡可重听；凭听到的发音在进度槽中拼出单词。
3. 拼对击碎 → 飘出单词与释义揭示，计入得分；拼错触发与词义关相同的"从头拼"惩罚；漏接扣心。
4. 10 词完成或 3 心耗尽结算；错词进错词本，与复习局联动。

## 关键业务对象及字段含义

- 听写局：运行时合成的关卡（direction='dictation'），词表来自所选成人词包，不入词包数据文件。
- 播放：使用 `speechSynthesis`，`lang='en-US'`，`rate=0.9`；重听无次数限制。

## 权限与可见范围

无账号体系；听写不产生星星、不影响解锁；错词写错词本（与 REQ-TC002 共用存储）。

## 边界场景与异常

- 不支持 / 无可用语音：入口隐藏；`startDictation` 兜底直接返回。
- 听写局中途 Esc / 回菜单：不结算、不写错词本（与全局"放弃不结算"一致）。
- 语音播报延迟或静音环境：玩家可无限次点击重听；不强制依赖音频也可凭进度槽长度作提示（但无释义，无法照抄）。

## 非功能要求

- 无新增外部依赖；不引入音频文件。

## 验收标准

1. 支持语音的浏览器中，成人词包分组出现"🎧 听写"；点击进入 HUD 标题为"🎧 听写挑战"的局。
2. 听写气泡不显示单词、音标与释义；词进入视野自动朗读一次；点击气泡重听。
3. 击碎时飘出单词 + 释义揭示；漏接 / 打错的词写入错词本。
4. 不支持语音合成的环境不渲染听写入口，其余功能不受影响。
5. 听写局不产生星星、不影响解锁。
6. smoke test 覆盖：入口显隐、听写局构建（词来自所选包、方向 dictation）、击碎采集入错词本、无语音环境降级。

## 待确认项

- 单局 10 词、语速 0.9 为当前假设值，落地后可调。
