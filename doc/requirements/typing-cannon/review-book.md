# 单词大炮 · 错词本（REQ-TC002）

## 背景

REQ-TC001 交付后，词义关的生词（漏接 / 打错）只在结算页展示一次，不持久化——玩家下次进入游戏后，上次的生词没有任何后续。碎片时间学习的关键闭环"错了 → 记住 → 复习 → 掌握"缺少后半段。

## 目标与范围

**本次覆盖**：
1. 采集与持久化：词义关结算时，把本局漏接 / 打错过的词连同音标、释义写入浏览器本地错词本。
2. 复习局：选关菜单新增"📖 错词复习"入口（显示当前词数）；进入后生成一局词义回忆关，词表取错词本中最久未练的至多 10 个词。
3. 毕业机制（简化 SRS）：复习局中某词**不打错且不漏接**地完整拼对 1 次记 1 次连对；连对 2 次视为已掌握，自动移出错词本；中途打错或漏接则连对清零、保留在本。
4. 复习局不产生星星、不影响关卡解锁。

**本次不覆盖（后置批次）**：按天数的间隔调度（今天 / 明天到期）、听写模式、自定义词表导入、跨设备同步。

## 用户角色

碎片时间成人学习者（与 REQ-TC001 一致）；儿童三种模式不接触错词本。

## 页面清单

- 选关菜单页：按钮排新增"📖 错词复习（N）"按钮，N=0 时置灰。
- 游戏页：复用现有画布与词义气泡，仅关卡来源不同（HUD 标题显示"📖 错词复习"）。
- 结算页：复用生词区块；复习局结算额外提示"本子剩余词数 / 已清空"。

## 核心业务流程

1. 玩家打词义关 → 漏接或打错某些词 → 结算时这些词写入错词本（已有条目则更新）。
2. 玩家回到菜单，看到"📖 错词复习（N）"，点击进入复习局。
3. 复习局掉落错词本中的词（与词义关同样的预展示与气泡交互）。
4. 完整拼对的词累计连对；连对 2 次毕业；打错 / 漏接连对清零。
5. 复习局结束（清完或失败）结算回写错词本；刷新页面后错词本保留。

## 关键业务对象及字段含义

- 错词条目：单词、来源词包、音标、中文释义、当前连对次数、最近接触时间。字段结构见契约 CON-TC002。
- 毕业连对阈值：2 次（固定常量，后续可调）。
- 复习局词表：按最近接触时间从旧到新取前 10 个。

## 权限与可见范围

无账号体系；错词本存于浏览器 localStorage，不区分玩家。

## 边界场景与异常

- 错词本为空：复习按钮置灰，不可点击。
- 复习局中失败（3 心用完）：词保留在本中，连对规则照常回写。
- 复习局中 Esc / 回菜单中途退出：本局不结算、错词本不变（与现有"放弃不结算"行为一致）。
- 同一单词理论上只存在于一个词包（包内唯一约束），条目按单词键控不歧义。
- 儿童抄写关（copy）不采集、不复习。

## 非功能要求

- 无新增外部依赖；存储沿用 localStorage 单键 JSON。
- 刷新 / 重开浏览器后错词本与连对进度保留。

## 验收标准

1. 词义关漏接或打错的词，结算后出现在错词本，菜单按钮计数增加；刷新页面后计数不变。
2. 复习局的词全部来自错词本；HUD 显示"📖 错词复习"。
3. 一个词连对 2 次后从错词本移除；中途打错或漏接后连对清零。
4. 复习局结算不产生星星，不影响任何词包的解锁状态。
5. 错词本为空时按钮置灰；清空后同样置灰。
6. smoke test 覆盖：采集写回、连对累计、毕业移除、清零重置、复习局构建、持久化。

## 待确认项

- 毕业阈值 2 次与单局词数 10 个为当前假设值，落地后可按体验调整。
