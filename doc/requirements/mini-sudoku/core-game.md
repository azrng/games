# 儿童数独 · 核心玩法（REQ-SD001）

## 背景

平台儿童向（kids）游戏缺少逻辑推理类内容。目录已预留 `mini-sudoku` 条目（`src/data/games.js`，`meta: { age: "kids", device: "all" }`），需要一个纯静态、双端可玩、纯点击交互的图案数独：用动物/水果 emoji 代替数字，从 4×4 小棋盘渐进过渡到 6×6，练习「每行、每列、每宫不重复」的观察与推理。

## 目标与范围

**本次覆盖**：
1. 12 关难度递进：第 1-6 关 4×4（2×2 宫，图案为 🐱🐶🐰🦊 四种动物），挖空数 4→8；第 7-12 关 6×6（2 行 3 列宫，图案为 🍓🍋🍇🍉🍑🥝 六种水果），挖空数 6→14；全部关卡唯一解，布局由种子随机生成、同种子可复现。
2. 纯点击交互：点击空格选中（高亮），再从底部图案盘点选填入；可覆盖修改；再点一次已选空格取消选中。
3. 软校验：填入后与同行/列/宫出现重复时，相关格子红闪标错并计一次「填错」；冲突实时高亮但不阻止填写、不锁死。
4. 过关判定与星级：全部填满且无冲突即过关，overlay 弹窗展示星星逐颗弹出动画；星级按填错次数评（0 次 ★★★、≤3 次 ★★、其余 ★）。
5. 存档（localStorage，键前缀 `mini-sudoku-`）：`mini-sudoku-unlocked-level`（已解锁关卡，只增不减）、`mini-sudoku-stars-<level>`（各关星级，保留最大值）。
6. 关卡选择弹窗（未解锁置灰、已解锁显示历史星级）、重开本关按钮、清空重来按钮（仅清非提示格）。

**本次不覆盖**：键盘/实体按键输入、音效与语音、答案提示（揭晓某格）、计时与排行榜、棋盘自定义尺寸、跨设备进度同步、平台目录/首页改动（目录条目已存在）。

## 用户角色

- 学龄前至小学低年级儿童：不识数字也能玩，通过图案观察完成行列宫不重复推理。
- 家长/教师：为孩子挑选合适的关卡起点，通过星级了解完成质量。

## 页面 / 模块清单

- `src/mini-sudoku/index.html`：游戏页骨架（页头、计分、棋盘、图案盘、关卡与结算弹窗）。
- `src/mini-sudoku/style.css`：自包含儿童向明亮主题（`--sd-*` 变量前缀）。
- `src/mini-sudoku/script.js`：游戏逻辑，纯函数挂 `window.SudokuApi` 供测试。
- `src/mini-sudoku/smoke.test.js`：node 原生 smoke 测试。

## 核心业务流程

1. 进入游戏：读取解锁进度，默认进入最高已解锁关卡；页头显示当前关卡，计分区显示「填错」与「剩余空格」。
2. 开局：按关卡配置（尺寸、宫形、挖空数）由种子生成唯一解棋盘，提示格直接展示且不可修改。
3. 填写：点空格选中 → 点底部图案填入；填入与同行/列/宫重复的图案时红闪提示并计一次填错，可立即换图案覆盖修正。
4. 冲突实时高亮：每次变更后重算全部冲突格并持续标红，修正后自动消除。
5. 过关：填满且无冲突 → 锁定棋盘 → overlay 弹窗星星动画 + 本关填错次数；保存星级、解锁下一关；第 12 关完成后不显示「下一关」。
6. 辅助操作：清空重来（仅清非提示格、填错计数归零）、重开本关（同种子重新生成同一布局）、关卡选择（12 关列表，未解锁置灰）。

## 关键业务对象

### 关卡档位

| 档位 | 关卡 | 棋盘与宫形 | 图案 | 挖空数 |
| --- | --- | --- | --- | --- |
| 4×4 档 | 1-6 | 16 格，2×2 宫 ×4 | 🐱🐶🐰🦊 | 4、5、6、7、7、8 |
| 6×6 档 | 7-12 | 36 格，2 行 3 列宫 ×6 | 🍓🍋🍇🍉🍑🥝 | 6、8、9、11、12、14 |

挖空数在各自棋盘档位内单调不减；跨档位时 6×6 起点重置为 6（棋盘变大，相对密度仍高于 4×4 终点，难度连续递增）。

### 生成规则

- 种子随机（mulberry32）→ 回溯生成完整解（候选随机顺序）→ 按难度随机选格挖空 → 逐格用解数计数器（上限 2）校验唯一解，不唯一则回填该格重试其余格子。
- 关卡种子由关卡号推导，同一关卡布局固定可复现；smoke 测试另用多种子验证生成稳健性。

### 星级与存档

- 星级：填错 0 次 3 星；≤3 次 2 星；其余 1 星。
- 存档键：`mini-sudoku-unlocked-level`（只增不减）、`mini-sudoku-stars-<level>`（保留最大值）。

## 边界场景与异常

- localStorage 不可用（隐私模式等）：读写静默降级到内存兜底，游戏可完整游玩，进度不持久化。
- 点提示格：不选中，提示「提示格不能修改哦」。
- 未选中空格点图案盘：提示「先点一个空格，再选图案吧！」，不计填错。
- 对已填格重复填入同值：不视为操作、不计填错。
- 填错（软校验）：红闪 + 计数，不阻止填写、不显示答案；玩家可覆盖修正。
- 第 12 关完成：结算弹窗不显示「下一关」，可再玩一次或从关卡选择重进。
- 清空重来只清玩家填入的格子，提示格保留。
- 页面标题、视口与共享返回按钮遵循平台移动端约定（见非功能要求）。

## 非功能要求

- 无构建、无框架、无 npm、无新增第三方依赖/CDN；目录自包含，静态打开即可玩。
- `<meta viewport>` 含 `viewport-fit=cover, user-scalable=no`；页头避让左上角悬浮返回按钮（移动端顶部预留 ≥56px）。
- 触控目标 ≥44px；双端纯点击即可完成全部操作。
- 全部文件 UTF-8，注释一律中文；JS 使用 ES6+，禁 var/eval/==，交互零 alert/confirm。
- 6×6 生成性能：回溯配最少候选优先（MRV）剪枝，12 关生成在数秒内完成（smoke 断言 24 次生成总耗时 < 20 秒）。
- `node src/mini-sudoku/smoke.test.js` 直接跑通，覆盖文件约定、唯一解生成、冲突判定、星级与存档。

## 验收标准

1. `node src/mini-sudoku/smoke.test.js` 输出 `mini sudoku smoke test passed`。
2. 页面约定：index.html 含 `viewport-fit=cover`、`user-scalable=no`、按序引入 `script.js` 与 `../js/game-back.js`；`src/data/games.js` 含 `slug: "mini-sudoku"` 与 `mobilePath: "src/mini-sudoku/index.html"`。
3. 生成：12 关 × ≥2 种子下，givens 全部来自 solution、提示盘解数为 1（唯一解）、solution 通过完整解校验；同种子完全可复现；总耗时 < 20 秒。
4. 冲突判定：行/列/宫冲突样例（含 4×4 与 6×6 宫形）冲突格集合正确，无冲突返回空。
5. 档位与星级：4×4→6×6 档位正确、挖空数端点正确且档位内单调不减；星级 0/≤3/其余 对应 3/2/1 星；unlocked 只增不减、stars 保留最大值、全新进度默认第 1 关。
6. 浏览器手工验证：点选空格与图案盘填入流转顺畅，冲突红闪与实时高亮正确，过关星星动画、关卡选择/重开/清空可用。
