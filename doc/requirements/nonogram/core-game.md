# 数织 · 核心玩法（REQ-NG001）

## 背景

平台网格解谜已有迷宫、一笔画、转管道、点灯，数织（Nonogram/Picross）补足"逻辑还原图像"体验：凭行列数字提示推理填格，完成时像素画显现，逻辑推理 + 成就感双满足，是 10-18 岁段公认的经典纸笔谜题数码化。

## 目标与范围

**本次覆盖**：
1. 经典数织：按行列提示数字填格/标叉，行列提示全部满足即完成，底图显现。
2. 关卡制三档规格：5×5（第 1-8 关）、10×10（第 9-20 关）、15×15（第 21 关起）；关卡由种子确定性生成，同关布局可复现。
3. 必有解且唯一解：生成时用行列线求解器传播验证唯一解，不唯一重抽种子（关卡生成确定性：从关卡种子起逐个派生种子尝试）。
4. 宽松判定：不逐格报错（数据宽松），完成时按"行列提示全部满足"判胜；提供揭示一格提示（每关 3 次，计入用时统计但不阻断星级）。
5. 双端操控：点按填格、再次点按标叉、三态循环（空→填→叉→空）；PC 右键直接标叉；长按标叉（移动端）。
6. 辅助显示：某行/列填格数达到提示和时该提示组变灰（仅表示"数量已满"，不判对错，保宽松）。
7. 计时与纪录：每关用时、历史最快用时；星级按用时与是否用提示评定（3 星=未用提示且用时低于阈值，2 星=未用提示，1 星=完成）；解锁递进，可回打已解锁关。
8. 接入平台首页游戏目录（age: all，device: all）。

**本次不覆盖**：彩色数织、超大规格（20×20+）、自定义图片导入出题、每日挑战。

## 用户角色

- **青少年（10-18 岁）**：主要玩家，喜欢逻辑推理与像素画收集感。

## 页面清单

- **对局页**（单页游戏）：页头（游戏名 + 关卡规格胶囊）、计时板（用时/提示剩余/最快纪录）、棋盘（左侧行提示列 + 顶部列提示行 + 中央格阵）、操作栏（撤销/重开/提示/选关）、完成弹窗（底图 + 星级 + 用时 + 下一关）、选关弹窗。
- 平台首页卡片（注册项）。

## 核心业务流程

1. 进入页面：加载当前关卡（首次第 1 关），棋盘按规格渲染，行列提示数字展示。
2. 玩家点格三态切换；提示组数量满足即变灰；5×5 顺滑完成后逐步挑战更大规格。
3. 每次操作后检查：所有行提示组与所有列提示组均满足 → 判胜（校验与底图一致），弹出完成弹窗（显现底图、星级、用时、是否最快纪录）。
4. 提示按钮：随机揭示一个未填对的正确格（置为"锁定正确"态），每关 3 次。
5. 星级与最快用时入档；下一关解锁；刷新后进度保留。

## 关键业务对象及字段含义

- **底图（solution）**：关卡唯一解布尔阵，由种子生成器产出。
- **提示组（clues）**：每行/列连续填格段长度序列，如 `[2,1]`；由底图计算。
- **格状态（cell）**：空 / 填 / 叉 / 锁定正确（提示产生）四态。
- **唯一解验证（solveUnique）**：线求解器逐行/列传播推理，能完全确定底图则唯一；推理中途矛盾或推不完则不唯一。
- **星级**：3 星=未用提示且用时 ≤ 目标阈值（5×5 30s / 10×10 150s / 15×15 420s），2 星=未用提示，1 星=完成；存档记历史最佳。

## 权限与可见范围

无账号体系，仅本机存档。

## 边界场景与异常

- **填满但行列不满足**：不判负不报错，玩家自行标叉排除（宽松原则）；提供"重开本关"。
- **提示已用完**：按钮置灰显示剩余次数。
- **15×15 生成耗时**：种子派生重试有预算上限（每关 2000 次派生），超预算降密度重试；保证出题等待无感（<1s 量级，实测校准）。
- **本地存储不可用**：可完整游玩，仅不记进度与纪录。
- **右键菜单**：棋盘上屏蔽浏览器右键菜单（标叉专用）。

## 非功能要求

- 棋盘用 CSS Grid/DOM 渲染（利于 smoke 与无障碍），格点触控目标 ≥ 28px。
- 技术形态与仓库现状一致：无框架、无构建、静态单页、UTF-8、中文注释，不新增第三方依赖。

## 验收标准

1. 平台首页出现「数织」卡片，可正常进入游玩。
2. 三态切换、右键/长按标叉、提示组变灰、行列提示渲染正确（对底图计算无误）。
3. 第 1-10 关生成的谜题均唯一解（smoke 用求解器验证）；完成判定准确。
4. 揭示提示 3 次限额、星级评定与最快用时入档，刷新后保留。
5. 选关仅开放已解锁关；跨档规格（5/10/15）随关卡正确切换。
6. smoke test（node 直跑）通过，覆盖提示组计算、唯一解验证、完成判定、三态切换、存档读写。
