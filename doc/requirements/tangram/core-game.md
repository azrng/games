# 七巧板 · 核心玩法（REQ-TG001）

## 背景

游戏平台已有逻辑推理与语文数学类游戏，缺少经典的几何空间启蒙品类。七巧板是中华文化经典的益智玩具，能锻炼儿童图形识别与空间想象能力，且规则零门槛：点选板块填满剪影即可。

## 目标与范围

**本次覆盖**：
1. 提供 12 关闯关制七巧板游戏，每关一个目标剪影（正方形 / 大三角形两类轮廓、多种不同拼法）。
2. 经典七块板块：2 大三角、1 中三角、2 小三角、1 正方、1 平行四边形；板块不旋转、不翻转，槽位固定。
3. 交互为纯点击（双端一致）：先点托盘中一块板，再点剪影上的槽位；类型匹配则吸附填入，不匹配仅抖动提示，**不计失误（零失败设计）**。
4. 提示三档递进：第 1-4 关槽位按板块类型着色；第 5-8 关灰色槽位描边；第 9-12 关纯剪影（点击处按最近未填槽位判定）。
5. 通关即 ★★★，进度与星级本地留存；有关卡选择、重开本关。

**本次不覆盖**：板块自由拖拽与旋转、自创关卡、计时排行。

## 用户角色

- 4-8 岁儿童：彩色提示档降低认知门槛。
- 成人与学龄儿童：灰影与纯剪影档挑战空间想象。

## 页面 / 模块清单

- 游戏页 `src/tangram/index.html`（拼板 SVG + 托盘 + 结算弹窗 + 关卡弹窗）
- 逻辑 `src/tangram/script.js`（关卡数据、匹配判定、最近槽位、存档）
- 样式 `src/tangram/style.css`、测试 `src/tangram/smoke.test.js`
- 目录注册 `src/data/games.js`（已预登记 slug `tangram`）

## 核心业务流程

1. 进入游戏，定位到最高已解锁关（无存档为第 1 关）。
2. 托盘按种子随机展示 7 块；玩家选板 → 点槽位 → 匹配则填入，集齐 7 块过关。
3. 过关按失误数评星，写入本地存档并解锁下一关。

## 关键业务对象

| 对象 | 含义 |
| --- | --- |
| 槽位（slot） | 剪影内与板块同形同向的目标多边形，按类型（L/M/S/Q/P）匹配 |
| 提示档（hint） | 0 彩色 / 1 灰影 / 2 纯剪影，按关卡序号 1-4 / 5-8 / 9-12 划分 |

零失败说明：板块类型不匹配不做任何数值记录，只做形状反馈；星级仅由通关与否决定。

## 边界场景与异常

- 未选板块直接点槽位：温和文字提示。
- 板块类型不匹配：槽位抖动 + 文字提示，不计任何数值。
- 重复点击已填槽位 / 已用板块：无效果。
- 同型多块（两大三角）与多槽位按类型互换，任意一块可填任意同型槽位。
- localStorage 不可用：降级为内存存档，游戏可玩。
- 关卡越界：钳制到 1-12。

## 非功能要求

- 无构建、无后端、无新依赖；移动优先，触控目标 ≥44px；纯剪影模式同样纯点击可玩。

## 验收标准

1. 12 关全部由合法七块拼法构成：采样校验无重叠、无空洞，槽位面积与类型一一对应（smoke 自动验证）。
2. 提示档按 1-4 / 5-8 / 9-12 递进。
3. 类型匹配才可填入；不匹配仅反馈不计数值；通关即三星并持久化。
4. 解锁进度只增不减，星级保留历史最大。
5. hub 目录可见七巧板卡片，移动端路由一致。

## 已确认记录

1. 2026-10-10 用户随开发指令确认需求（十款启蒙益智游戏整批立项）并直接落地，不单独走文档评审轮次。
2. 2026-10-10 开发核实：关卡数据由精确覆盖搜索器生成（细网格采样 + 严格计数验收），smoke 测试内置采样复检，保证 12 关全部为可拼合的合法布局。
3. 2026-10-11 用户复核后指示：板块放错不计失误（去掉失误计数），星级改为通关即三星，对齐平台低龄游戏的零失败基调；验收标准 3 同步更新。
