# 24 点 · 技术设计（DES-MT001）

## 需求追溯

实现 REQ-MT001 全部验收标准；无契约文档。

## 技术设计

**文件结构**：`src/math-24/` 四件套（DOM 交互为主，对齐 `src/lights-out/` 惯例；出题验证模式参考 `src/math-hero/` 的生成器正确性 smoke）。

**script.js 架构**：
- IIFE + 首行 `// @ts-check` + 全中文注释；常量：`SLUG = "math-24"`、存档键 `math24-best-time-<tier>` / `math24-streak-<tier>`、目标值 24。
- 分数模块（纯函数）：
  - `frac(n, d)`：构造并约分（辗转相除），d ≤ 0 归一化符号，d = 0 返回 `null`。
  - `fAdd/fSub/fMul/fDiv/fEq/fIsInt`：分数四则与判等，除零返回 `null`。
- 求解器（纯函数，挂 `window.Math24` 导出）：
  - `solve24(cards)`：递归两两归约——每步任取两数按六种合成（a+b、a-b、b-a、a×b、a÷b、b÷a）合并，剩 1 数时判等 24；用「值 + 参与运算的原始数字多重集」做去重键（交换律等价、括号等价只留一条）；返回 `["(3+3/7)×7", ...]` 按整数中间值优先、表达式短优先排序。
  - `generatePuzzle(tier, random)`：按档随机抽 4 数（入门 1-10、进阶 1-13、大师 1-13），`solve24` 验证有解；大师档额外要求"全部解法都含非整数中间值"（即不存在纯整数路径解），最多尝试 400 次后放宽为"存在含分数中间值解"兜底。
- 交互状态：`cards`（当前场上卡数组，含 `expr` 来源串）、`selected`（先点卡下标）、`pendingOp`（当前运算符）、`undoStack`（每次合并前压栈快照）。
- 合成规则：点卡 A（高亮）→ 点运算符 → 点卡 B：`value = op(A.value, B.value)`，为 `null`（除零）时抖动提示不合并；成功后新卡落在 A 的位置（expr 重写），B 位置移除；场上 1 卡时判等 24 → 成功流程。
- 计时：本题首操作起计时（rAF 或 setInterval 100ms），答对停表；跳过不计。

**存档**：`math24-best-time-<tier>`（秒字符串）、`math24-streak-<tier>`（当前与最高连击 JSON）。


## 交互与异常

- 只剩 1 卡且 ≠24 时提示"不等于 24，可撤销重试"，不判负。
- 键盘等效操作（数字序号选卡、+−*/ 选运算符、Backspace 撤销）作为 PC 增强，非必须。
- 换难度/下一题时清空选择与撤销栈、重置计时。
- 存储读写 try/catch 静默降级；smoke 以 `window.Math24` 导出纯函数断言。
