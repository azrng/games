# 七巧板 · 核心玩法设计（DES-TG001）

## 需求追溯

- 关联 REQ-TG001 全部「本次覆盖」范围；「本次不覆盖」项（自由拖拽旋转、自创关卡、计时排行）未实现。

## 技术设计

### 模块职责与数据流

```text
LEVELS（内嵌 12 关数据） ─▶ renderBoard() SVG 槽位层 + 已填层
PIECE_DEFS（七块标准形态） ─▶ renderTray() 托盘按钮（shuffleTray 种子洗牌）
点击托盘/槽位 ─▶ matchPiece() 类型判定 ─▶ 填入或仅反馈（零失败） ─▶ finishLevel() 通关三星与存档
```

- 关卡数据：`LEVELS` 内嵌 12 关，每关 `{name, w, h, hint, samples, slots[]}`；槽位多边形顶点为真实尺寸 2 倍刻度（全整数，避免小数渲染误差）。
- 关卡来源：Python 精确覆盖搜索器（160×160 细网格 + 抖动采样 + 严格计数）穷举生成，方形与三角形各取 6 种不同拼法；smoke 测试用同口径采样复检（单覆盖数 = 期望值且无重叠）。
- 提示档渲染：彩色档槽位填充类型色 25% 透明 + 同色描边；灰影档统一灰填充描边；纯剪影档全部槽位同色无描边（内部边界不可见），整板点击按最近未填槽位判定。
- 类型色即匹配语义：同型板块/槽位同色（两大三角同为橙色），配色提示不会误导互换。

### 技术决策

1. **点选吸附而非自由拖拽**：移动端零误触、逻辑可测；类型匹配即可填入，位置由槽位数据给出。
2. **板块不旋转**：槽位与板块同形同向，匹配按类型（L/M/S/Q/P）判定，同型互换；避免旋转自由度带来的儿童挫败。
3. **关卡数据离线生成 + 采样自检**：拼合正确性（无重叠/无空洞）不在运行时计算，smoke 测试以同口径采样复检兜底（`countSamples` 口径：步长 1、偏移 (0.37,0.61)，与生成器一致，任意 45° 边不穿过采样点）。
4. **SVG 双层渲染**：槽位层 + 已填板块层分离，填入动画只作用于已填层，槽位层状态稳定。
5. **存档沿用模板模式**：`tangram-unlocked-level` 只增不减、`tangram-stars-<n>` 保留最大值，localStorage 异常降级内存。
6. **纯剪影点击容错**：点击坐标换算到关卡坐标系后取质心距离最近的未填槽位，天然容错儿童点偏。
7. **零失败计分（2026-10-11 修订）**：板块放错只做抖动与文字反馈，不设失误计数状态；`starRating()` 恒返 3（通关即三星），存档接口保留 `stars-<n>` 便于未来引入难度计分；对齐拼音打字乐园的零失败基调（REQ-TG001 已确认记录 3）。

## 界面原型

```text
┌────────────────────────────────────┐
│ TANGRAM            第 1 关          │
│ 七巧板                              │
│ ┌失误──┐ ┌已拼──┐ ┌本关最佳┐        │
│ │  0   │ │ 0/7  │ │  --   │        │
│ └──────┘ └──────┘ └───────┘        │
│ ┌──────────────────────────────┐   │
│ │  ◺ ◹ 彩色槽位剪影            │   │
│ │  ◺ ▣ ◺ ...
│ └──────────────────────────────┘   │
│ ┌──[◺]──[◿]──[▣]──[◺]──[◿]──┐     │
│ │        托盘（点选高亮）      │     │
│ └────────────────────────────┘     │
│ 按颜色拼 · 正方形                   │
│      [重开本关]  [关卡选择]          │
└────────────────────────────────────┘
```

- 纯剪影态：槽位层统一深色，无描边；点击板面即判定最近槽位。
- 过关弹窗：星级 + 失误数 + 历史最佳，按钮「再玩一次 / 下一关」（末关隐藏下一关）。
- 关卡弹窗：4 列关卡格，未解锁置灰，显示历史星级。

状态说明：无 loading（数据内嵌同步渲染）；empty/error 不适用（无异步数据源）。

## 交互与异常

### 操作流程

1. 进入 → `startLevel(min(解锁关, 12))` → 渲染拼板 + 洗牌托盘。
2. 点托盘板块 → 高亮选中（再点取消）；点槽位 → 类型匹配则填入（pop 动画），不匹配仅抖动与红字提示（零失败，无数值记录）。
3. 集齐 7 块 → 450ms 后弹结算（通关三星）→ 星级/解锁写存档。
4. 「重开本关」随时可用；「关卡选择」打开关卡弹窗。

### 边界与异常处理

| 场景 | 处理 |
| --- | --- |
| 未选板块点槽位 | 文案提示 |
| 板块类型不匹配 | 槽位抖动 + 文字提示，不计数值（零失败） |
| 点击已填槽位 / 已用板块 | 无效果 |
| localStorage 不可用 | 内存兜底存档 |
| 关卡号越界 | 钳制到 1-12 |
| prefers-reduced-motion | 关闭抖动/弹入动画 |

### 验证方式

1. `node src/tangram/smoke.test.js`（已通过）：文件与目录约定；托盘/槽位面积与类型多重集；12 关采样级拼合校验（无重叠、单覆盖数 = 期望）；提示档递进；最近槽位判定；洗牌复现；通关三星与存档边界（并断言零失败设计：无失误计数状态与页面元素）。
2. 浏览器手工 smoke（390px 视口）：彩色/灰影/纯剪影各过一关、失误抖动反馈、过关弹窗与关卡跳转、返回按钮避让、无 console 报错。
