# 单词大炮 · 成人词包与词义模式 · 设计（DES-TC001）

## 需求追溯

- 覆盖 REQ-TC001 全部范围项（词包系统、成人词包、词义模式、结算生词回顾）；"待确认项"按文中假设值实现，落地后可在数据层微调。
- 不覆盖项（听写模式、自定义导入、SRS 复现、Boss 战、皮肤）不在本设计内。

## 契约引用

- 词包数据结构：CON-TC001（**待落地草案**）；阶段 1 以 `src/typing-cannon/wordpacks.js` 落地后代码为事实来源。
- 不涉及后端接口与事件契约。

## 技术设计

### 模块职责

| 模块 | 职责 |
| --- | --- |
| `wordpacks.js`（新增） | 纯数据：`window.WordPacks` 数组，含 kid-core（现有 12 关迁移）与 daily-core（成人 10 关）两个内置包 |
| `script.js` 引擎 | 读词包渲染选关网格、驱动对局、按 `direction` 切换气泡渲染、记录并展示生词 |
| `smoke.test.js` | 加载 `wordpacks.js` 按 CON-TC001 校验规则断言；保留现有引擎回归 |

### 数据流向与状态变化

```text
wordpacks.js ──window.WordPacks──▶ script.js
   选关：按 包→组(每3关)→关 渲染 enGrid，成人组标题追加"🧠 词义回忆"标注
   对局：G.pack=当前包; G.entry=当前关配置
     direction==='recall' 时 spawnItem 附加 zh/ipa，气泡渲染中文释义
     handleChar/loseLife 按 REQ 规则写入 G.wrongWords / G.missedWords
   结算：openEnOver 渲染"本局生词"区块（去重合并两类来源）
存档：enSave.stars 由 {数字:星} 迁移为 { 包id: {关序:星} }
     加载时检测旧数字键且无 kid-core → 自动迁移并持久化（一次性）
解锁：enUnlocked(packId, i) 改为按包内前一关星星判断；kid-core 迁移后规则不变
```

### 关键技术决策

1. **同关首字母唯一**（数据约束）替代"点击选目标"交互：现有 `handleChar` 锁定规则零改动，避免新增 pointer 命中检测与提示 UI。词包编排时保证，smoke 校验兜底。落地修正：该约束仅作用于 recall 关（盲打场景）；copy 关单词可见，kid-core 历史数据（cat/cup、moon 重复）保持原样。
2. **recall 气泡渲染**：复用现有逐字母绘制，未打字母画为下划线槽 `_`（保留长度提示），已打字母绿色填充，当前锁定字母黄色高亮——与 copy 模式同一套代码路径，仅字符源不同。
3. **词条预展示**：recall 卡进入视野（y>70）后才开始 1.5 秒预展示计时，期间半速下坠并显示完整词条（单词+音标+释义），归零后恢复常速仅显示释义。（实现修正：原设计从出生即倒计时，实际气泡尚在屏幕外，预展示不可见；浏览器实测发现后改为入视野触发。）
4. **生词记录**：`loseLife(it)` → `G.missedWords`；`handleChar` 误按且存在 `G.lock` 时 → `G.wrongWords` 记 `G.lock`。无锁定时的误按视为手误不记录。对局结束两类按 `w` 去重合并；不持久化（REQ 边界）。
5. **发音**：`'speechSynthesis' in window` 为真才渲染 🔊；点击 `speak(w)`，`lang='en-US'`，`rate=0.9`。不引依赖。
6. **文案语气**：`tone==='adult'` 时 toast 与结算文案走成人语气（去感叹化、强调数据：WPM/准确率/生词数）；现有文案本已中性（姓名已移除），仅差异处维护一张小映射表，不新建文案系统。
7. **THEMES 移除**：script.js 不再持有词库，原 `THEMES[i]` 的全部消费点改为从 `G.pack.levels[i]` 取值；`MIX_POOL` 大乱斗逻辑保留在 kid-core 末关。
8. **包内唯一与首字母唯一约束仅约束 recall 词**：生词记录按词键控不允许歧义；儿童抄写词保留历史数据（终极混战关内已去重）。

### 依赖边界

- 不新增运行时依赖；`wordpacks.js` 与引擎同目录，`index.html` 以两个 `<script>` 顺序引入（数据在前）。
- 平台首页（`index.html`）与共享返回按钮（`js/game-back.js`）不受影响。

## 交互与异常

| 场景 | 处理 |
| --- | --- |
| 误按（无任何词匹配） | 现有规则：断连击 + 错误音效；若有锁定词记入生词 |
| 词落地（漏接） | 扣心 + 记入生词；lives≤0 结算 |
| Esc 放弃 | 直接回菜单，不展示生词（REQ 边界） |
| 释义过长 | `measureText` 后超出气泡最大宽（min(W-160, 240px)）则字号从 15px 逐级降 1px，最低 11px |
| 旧存档 | 迁移函数幂等：仅当存在数字键且无 `kid-core` 时执行一次 |
| 无 TTS | 🔊 不渲染，其余不变 |
| 词包数据损坏 | smoke 构建期校验拦截；运行时 `WordPacks` 缺失时回退仅无尽+字母练习并 console 警告 |

## 验证方式

1. `node smoke.test.js`：新增词包结构校验（CON-TC001 全部规则）、存档迁移幂等断言；现有引擎回归用例全部保留并通过。
2. 手工冒烟：成人关打通一关看星星与解锁；漏接一词确认结算生词区出现并可发音；儿童关与无尽模式回归。
