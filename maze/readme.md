## 迷宫冒险说明

### 当前玩法
- 选择简单、中等、困难三档难度进入游戏。
- 使用键盘方向键或 `WASD` 控制角色移动。
- 桌面端专用，移动设备会显示不支持提示。
- 找到终点处的伙伴后进入下一关。

### 难度设计
- 简单：`13 x 13` 起步，后续每关持续扩张。
- 中等：`19 x 19` 起步，迷宫更大、回溯成本更高。
- 困难：`27 x 27` 起步，视野更紧，路线更长。
- 关卡推进时会同时提升迷宫尺寸，并逐步压缩单格尺寸，所以越往后越难。

### 本次 UI 优化
- 整体升级为「探险手账」风格：延续游戏平台浅色主题，叠加暖色晨光背景、藏宝图坐标网格和舞台暗角。
- 迷宫重绘：立体受光石墙、羊皮纸地面、琥珀色足迹光点，终点改为持续脉动的营火信标。
- 玩家角色新增提灯光晕呼吸动画，角色表情重绘（描边、眼神高光、腮红）。
- 侧栏 HUD 重构：顶部探险配色光带、渐变标题、统计卡入场动画与悬停反馈，新增键位操作提示卡。
- 难度选择卡拥有独立配色身份（轻探绿 / 追踪琥珀 / 深渊红）、大号水印徽记与悬停 CTA。
- 通关结算升级为弹跳入场的庆祝卡片；修复返回按钮与侧栏重叠的问题。
- 遵循 `prefers-reduced-motion`，用户偏好减少动效时自动关闭动画。

### 运行方式
- 直接在浏览器中打开 `index.html` 即可游玩。
